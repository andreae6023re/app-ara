# ARA · Comidas

Aplicación independiente para planificación de comidas, recetas, inventario y lista de compra.

## Desarrollo local

```bash
npm install
npm run dev
```

## Supabase

Copia `.env.example` a `.env` y añade:

```env
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

No subas `.env` a GitHub.
